# Gemini install doc — বাংলা

ZaRa-র Gemini engine install করার আগে এই doc ফাইলটি পড়ে নিন। ইনস্টলের ক্রম অপরিবর্তনীয়:

**ধাপ ১ — Doc ফাইল (এখন):** এই নথিটি দেখে নিশ্চিত করুন যে আপনি কোন মোডে চলছেন বুঝেছেন।

**ধাপ ২ — Gemini engine install:** Doc দেখা হয়ে গেলেই “ইঞ্জিন ইনস্টল করুন” বাটন সক্রিয় হবে। ইনস্টল মানে হলো ZaRa-র Gemini engine কে সক্রিয় করা — এটি কোনো Google অ্যাপ বা সিস্টেম ফাইল পরিবর্তন করে না।

**ধাপ ৩ — Key বা backend সেট করুন:**
- Settings → Gemini setup → API key-এ নিজস্ব Gemini API key দিন (শুধু এই ডিভাইসে এনক্রিপ্ট করে রাখা হয়), **অথবা**
- Settings → Backend proxy-তে নিজস্ব Python backend-এর URL দিন।

**মনে রাখবেন:**
- ZaRa আপাতত শুধু বাংলা কথা বলে। ASR, TTS ও মডেল প্রম্পট সব বাংলা।
- বাইরের কোনো কাজ (মেসেজ, কল, ইমেইল) কখনো নিশ্চিতকরণ কার্ড ছাড়া পাঠানো হয় না।
- কোনো Maya অ্যাসেট, মডেল বা লাইসেন্স কোড এখানে ব্যবহার করা হয়নি — এটি সম্পূর্ণ clean-room বাস্তবায়ন।
